# 📚 My Learning Progress Dashboard

A clean and simple **personal learning tracker** designed to track my daily progress in **DSA, technical skills, projects, and study activities**.

The goal of this project is to maintain all my learning progress in one place and make it easy to see what I have completed, what I am currently learning, and what I need to work on next.

## 🚀 Features

* 📊 Learning progress dashboard
* 🧠 DSA progress tracking
* 💻 Technical skills tracking
* 🚀 Project progress tracking
* 📅 Daily learning activity
* 📈 Progress visualization
* 💾 Data stored using browser `localStorage`
* 🧹 Clean and simple UI
* 📱 Responsive design

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and responsive UI
* **JavaScript** – Functionality and data management
* **LocalStorage** – Browser-based data persistence
* **Google Fonts** – Typography

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No backend or database setup is required.

## 💾 Data Storage

This project currently uses browser **localStorage** to store learning data.

Storage key:

```text
learning-progress-dashboard-v2
```

This means the data is stored locally in the user's browser.
